# BelenClient

**BelenClient** is a private Minecraft client designed for users who want to play Minecraft **offline**, without requiring an internet connection to launch or use the client.

> **⚠️ BelenClient is NOT a hack client.**

It does **not** include cheats, exploits, combat modifications, or other gameplay advantages.

## ✨ Features

* 🎮 Runs the **latest Minecraft version**
* 📴 Designed to work **without an internet connection**
* 👤 Enter **any username of your choice**
* 🔑 **Activation key required** to use the client
* 🖥️ Supports **Singleplayer**
* 🌐 Supports **offline/private servers**
* 🚀 Lightweight private client
* 🧩 Uses **Fabric**
* 🖥️ Includes **Iris** for graphics/shader support
* 🔄 Updated when a new Minecraft version is released

## 📌 Current Version

**Minecraft:** `26.2`

BelenClient will be updated whenever a new Minecraft version is released.

## 🔐 Activation System

A valid **BelenClient activation key is required** to use the program.

Keys are managed separately and are required before the client can be launched.

## 📴 Offline Mode

BelenClient is designed for environments where an internet connection is unavailable.

Users can enter **any username they choose** and launch Minecraft without requiring an online Minecraft account for the client itself.

This allows users to:

* Play Singleplayer
* Play on appropriately configured offline/private servers
* Use a custom username

> **Note:** Server owners determine whether offline-mode connections are permitted. BelenClient does not bypass authentication on servers that require online authentication.

## 🧩 Fabric & Iris

BelenClient strictly uses **Fabric** as its Minecraft modification framework.

The client includes **Iris** for shader and graphics functionality.

No additional gameplay-altering modifications are included.

### No Hack Client

* ❌ Auto Clicker
* ❌ Reach modifications
* ❌ ESP
* ❌ Combat cheats
* ❌ Exploits

**BelenClient is strictly intended to be a private offline Minecraft client, not a cheat client.**

## 📋 Requirements

* Windows PC
* BelenClient activation key
* Java/runtime requirements appropriate for the included Minecraft version
* Minecraft version supported by the current BelenClient release

An internet connection is **not required to launch the client after the required files have been installed/provided**.

## 🔄 Updates

BelenClient follows Minecraft releases.

When Minecraft receives a new version, BelenClient will be updated to support the new version where possible.

## 🎯 Purpose

BelenClient was created for users who want a simple and private way to launch Minecraft in offline environments while still being able to choose their own username.

The goal is to provide a lightweight client without unnecessary gameplay modifications.
